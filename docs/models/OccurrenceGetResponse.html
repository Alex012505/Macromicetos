OccurrenceGetResponse

  • occurrence_id : String
    Identificador único de la ocurrencia (Texto)
  • basis_of_record : String
    Tipo de registro según Darwin Core
  • substrate : String
    Sustrato biológico o físico donde se encontró
  • identified_by : String
    Persona que determinó taxonómicamente el espécimen
  • date_identified : date
    Fecha de la determinación taxonómica
  • occurrence_remarks : String
    Notas adicionales sobre el organismo observado
  • taxon : OccurrenceGetResponse_taxon
  • event : OccurrenceGetResponse_event
  • multimedia : List
    Fotografías asociadas al espécimen de campo
