EventInput

  • location_id : UUID
    Llave foránea que enlaza al sitio (`ecological.location`) creado previamente
  • event_type : String
    Tipo de evento o episodio de muestreo
    Enum:
    Observation
    Survey
    Expedition
    SiteVisit
    SamplingEvent
  • field_number : String
    Código de campo estándar (Convención AAAA-REG-NN)
  • event_date : date
    Fecha en que se realizó el evento de muestreo (ISO 8601)
  • recorded_by : String
    Persona o recolector normalizado responsable de la salida
  • sampling_protocol : String
    Protocolo estandarizado de búsqueda o muestreo
    Enum:
    OpportunisticSearch
    LinearTransect
    FixedPlot
  • sampling_effort : String
    Esfuerzo de muestreo aplicado (ej. 1 observer-hour)
  • event_remarks : String
    Observaciones generales del evento de campo
