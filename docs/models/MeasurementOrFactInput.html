MeasurementOrFactInput

  • event_id : UUID
    Vínculo opcional al evento de campo (ej. variables climáticas globales).
  • occurrence_id : UUID
    Vínculo opcional a una ocurrencia específica (ej. medidas morfológicas).
  • measurement_type : String
    Tipo de medida o variable capturada (según catálogo o ENUM).
    Enum:
    temperatura
    humedad
    presion
    diametro_sombrero
    color_sombrero
  • measurement_value : String
    Valor registrado (admite números, rangos o descripciones de texto).
  • measurement_unit : String
    Unidad de medida correspondiente (ej. °C, %, cm)
