LocationInput

  • country : String
    País de la observación (fijo en Colombia)
  • state_province : String
    Departamento o división territorial
  • municipality : String
    Municipio de la recolección
  • locality : String
    Descripción textual específica del sitio
  • decimal_latitude : Double
    Latitud en grados decimales (WGS84)
  • decimal_longitude : Double
    Longitud en grados decimales (WGS84)
  • elevation_m : Float
    Altitud en metros sobre el nivel del mar
  • coordinate_uncertainty_m : Float
    Radio de incertidumbre del GPS en metros
  • habitat : String
    Vocabulario controlado de hábitats de la Orinoquía
    Enum:
    Bosque de galería
    Sabana abierta
    Riberas de río
    Bosque secundario
  • location_remarks : String
    Notas adicionales sobre el sitio de muestreo
