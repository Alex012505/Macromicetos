OccurrenceInput

  • event_id : UUID
    Llave foránea al evento de campo (`ecological.event`)
  • taxon_id : UUID
    Llave foránea al diccionario autoritativo de especies (`shared.taxon_ref`)
  • external_occurrence_id : String
    Identificador externo (ej. gbifID) para garantizar idempotencia.
  • basis_of_record : String
    Tipo de registro según Darwin Core (fijo en HumanObservation)
  • substrate : String
    Sustrato biológico o físico donde se encontró (ENUM de 52 valores).
    Enum:
    Madera muerta
    Suelo orgánico
    Hojarasca
    Estiércol
  • identified_by : String
    Persona que determinó taxonómicamente el espécimen.
  • date_identified : date
    Fecha de la determinación taxonómica.
  • occurrence_remarks : String
    Notas libres sobre el organismo observado.
